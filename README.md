# EsterilControl

App web para el control, manejo y gestión de ciclos y paquetes de esterilización con óxido de etileno (ETO).

## Características principales
- Gestión de ciclos de esterilización.
- Registro y trazabilidad de paquetes.
- Panel administrativo para configuración de usuarios y mantenimiento.
- Generación de reportes automáticos.
- la idea es crear un repositorio mobil donde se pueda usar desde el telefono o pc.
- control de orden en archivos.

## Tecnologías utilizadas
- **Lenguaje:** Python
- **Framework:** Streamlit
- **Generación de PDFs:** ReportLab
